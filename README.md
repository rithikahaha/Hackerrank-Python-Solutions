# HackerRank Python Solutions

Step-by-step solutions to HackerRank's Python questions, written for beginners.
The goal isn't just "here's the answer" — it's showing how to think through each
problem so the logic actually makes sense.

## How each problem is organized

Every folder has:
- **`README.md`** — the problem in plain English, the steps to solve it, the code, and a walkthrough of what each line does
- **`solution.py`** — just the clean code, ready to run

Try the problem yourself first. If you get stuck, read the **Steps** section (not
the code) — it's meant to unstick your thinking without giving the answer away.
Only look at the code once you've had a real attempt.
